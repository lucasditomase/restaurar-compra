# Restaurar compra

- Si compraste la aplicación cuando era una descarga de pago, puedes mantener las funciones originales de forma gratuita. No se requiere suscripción.
- Las compras se restauran automáticamente. Si esto no funciona para ti, infórmame para que pueda arreglarlo.
- El botón para restaurar las compras en el menú de suscripción solo funciona para suscripciones. No tendrá ningún efecto en las descargas pagadas.
- El botón de restauración en el menú de compra única solo funciona para compras dentro de la aplicación; no funciona para compras pagadas por adelantado.

## Informar de un problema

- Si la aplicación no reconoce su compra, póngase en contacto conmigo desde la página de atención al cliente y adjunte una captura de pantalla del recibo de compra.
- Para obtener más información, consulte la [lista de aplicaciones](https://github.com/lucasditomase/purchases-restored) que admiten la restauración de compras.

## Cómo obtener el recibo de compra

- En iPhone y iPad, abre la App Store y toca tu foto de perfil. Luego, vaya a Aplicaciones e Historial de compras.
- En Mac, abre la App Store, haz clic en tu foto de perfil y luego en Configuración de la cuenta. Por último, vaya a Aplicaciones e Historial de compras.
- Puedes filtrar las aplicaciones por fecha usando el menú de la parte superior.
- Los recibos de compra no desaparecen. Incluso si hiciste una compra hace años, todavía estará allí.
